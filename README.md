# Flow Repair Autopilot

Локальный помощник для генерации последовательных кадров ремонтного таймлапса в Google Flow.

Приложение ведет проект от общей идеи до таблицы кадров, генерирует следующий промпт с учетом уже полученного изображения и может управлять Flow в Chrome через Playwright. Внешние API не используются: анализ кадров рассчитан на локальные модели через Ollama или LM Studio.

## Что умеет v1

- Создает проект с концепцией, стилем, форматом, количеством кадров и этапами ремонта.
- Хранит кадры в `project.json`: этап, цель, промпт, путь к картинке, оценка, заметки и следующий шаг.
- Генерирует стартовые промпты и следующий промпт на основе предыдущего результата.
- Анализирует кадр локальной vision-моделью:
  - Ollama: например `llava:7b`, `llava-llama3`, `minicpm-v`.
  - LM Studio: OpenAI-compatible локальный сервер.
- Открывает Flow в Chrome, вставляет промпт, запускает генерацию и сохраняет скриншот результата.
- Если Flow изменил интерфейс, приложение просит ручное действие, а проект продолжает жить.

## Установка

1. Установи Python 3.11+.
2. Установи зависимости:

```powershell
.\install.ps1
```

3. Для локального анализа кадров выбери один вариант:

Ollama:

```powershell
ollama pull llava:7b
ollama serve
```

LM Studio:

- Запусти локальный сервер в LM Studio.
- Загрузи vision-модель.
- Убедись, что сервер доступен по `http://localhost:1234/v1/chat/completions`.

## Рабочий процесс

1. Заполни концепцию видео, стиль, формат, количество кадров и этапы.
2. Нажми `Создать план кадров`.
3. Выбери кадр и нажми `Отправить в Flow`.
4. Когда Flow закончит генерацию, нажми `Сохранить скриншот Flow`.
5. Нажми `Анализировать кадр`.
6. Нажми `Сделать следующий промпт`, чтобы уточнить следующий кадр по фактическому результату.

## Настройки Flow

Автоматизация Flow находится в `flow_autopilot/browser_operator.py`.

По умолчанию используются эвристики для поиска поля ввода и кнопки генерации. Если Google поменяет интерфейс, открой `Настройки` в приложении и задай CSS-селекторы вручную:

- Prompt field selector
- Generate button selector
- Result selector

## Ограничения

- Flow не предоставляет публичный API для этого сценария, поэтому браузерная автоматизация может ломаться при изменениях интерфейса.
- Приложение не обходит логин, подписку, лимиты или правила Flow.
- v1 работает только с картинками. Видео/оживление можно добавить отдельным этапом после стабилизации пайплайна кадров.
